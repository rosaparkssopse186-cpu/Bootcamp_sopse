
 ## Financial Tracker
 
Project overview:
Finance Tracker is a Java-based command-line application designed to help users manage and monitor their financial transactions. The application allows users to record deposits, track payments, view transaction history, and generate financial reports.



## Features

Add Deposit: Record incoming money.

Make Payment: Record expenses and outgoing payments.

View Ledger: Display all transactions, deposits, and payments.

Financial Reports: View Month to Date, Previous Month, Year to Date, and Previous Year reports.

Search Vendor: Find transactions by vendor.

Account Summary: View total deposits, total payments, and account balance.

Data Storage: Save and retrieve transactions using a CSV file.




## How to Run

Install Java JDK and IntelliJ IDEA.

Clone the GitHub repository.

Open the project in IntelliJ IDEA.

Navigate to Main.java.

Run the main() method.
